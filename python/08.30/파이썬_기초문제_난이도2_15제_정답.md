## 1. 리스트에서 짝수만 골라내기

```python
numbers = [3, 8, 11, 14, 20, 25, 30]

result = []

for number in numbers:
    if number % 2 == 0:
        result.append(number)

print(result)
```

결과:

```text
[8, 14, 20, 30]
```

**해설:** `% 2 == 0`이면 2로 나누었을 때 나머지가 0이므로 짝수입니다. 짝수만 `append()`로 새 리스트에 추가합니다.

## 2. 문자열에서 특정 문자 개수 세기

```python
text = "banana apple"

count = 0

for char in text:
    if char == "a":
        count += 1

print(count)
```

결과:

```text
4
```

**해설:** 문자열도 `for`문으로 한 글자씩 꺼낼 수 있습니다. `"a"`를 만날 때마다 `count`를 1 증가시킵니다.

## 3. 점수에 따라 등급 출력하기

```python
score = 83

if score >= 90:
    print("A")
elif score >= 80:
    print("B")
elif score >= 70:
    print("C")
else:
    print("D")
```

결과:

```text
B
```

**해설:** 조건문은 위에서부터 검사합니다. 83은 90 이상은 아니지만 80 이상이므로 `"B"`가 출력됩니다.

## 4. 리스트에서 최댓값 직접 찾기

```python
numbers = [12, 7, 25, 9, 18]

maximum = numbers[0]

for number in numbers:
    if number > maximum:
        maximum = number

print(maximum)
```

결과:

```text
25
```

**해설:** 첫 번째 숫자를 임시 최댓값으로 잡은 뒤, 더 큰 숫자를 만날 때마다 `maximum`을 변경합니다.

## 5. 중복 데이터 제거하기

```python
names = ["민수", "지수", "민수", "영희", "지수", "철수"]

result = set(names)

print(result)
```

출력 예시:

```text
{'민수', '지수', '영희', '철수'}
```

**해설:** `set`은 같은 값을 중복해서 저장하지 않으므로 리스트의 중복 제거에 사용할 수 있습니다. 집합은 출력 순서가 달라질 수 있습니다.

## 6. 딕셔너리에서 평균 점수 구하기

```python
scores = {
    "민수": 80,
    "지수": 95,
    "철수": 70,
    "영희": 85
}

total = sum(scores.values())
average = total / len(scores)

print(average)
```

결과:

```text
82.5
```

**해설:** `scores.values()`는 딕셔너리의 값인 점수들만 가져옵니다. 점수의 합을 학생 수로 나누면 평균입니다.

## 7. 3의 배수 합 구하기

### 방법 1

```python
total = 0

for number in range(1, 31):
    if number % 3 == 0:
        total += number

print(total)
```

결과:

```text
165
```

### 방법 2

```python
total = 0

for number in range(3, 31, 3):
    total += number

print(total)
```

**해설:** `range(3, 31, 3)`은 3부터 시작하여 3씩 증가하므로 3의 배수만 만들어냅니다.

## 8. 입력값을 숫자로 안전하게 변환하기

```python
user = input("숫자 입력: ")

try:
    number = int(user)
    print(number)
except ValueError:
    print("숫자를 입력해주세요.")
```

**해설:** `int()`로 바꿀 수 없는 문자열이 들어오면 `ValueError`가 발생합니다. 이를 `except`에서 처리합니다.

## 9. 양수만 더하는 함수 만들기

```python
def positive_sum(numbers):
    total = 0

    for number in numbers:
        if number > 0:
            total += number

    return total


numbers = [-3, 5, 7, -2, 10]

print(positive_sum(numbers))
```

결과:

```text
22
```

**해설:** 함수가 리스트를 입력받고, 양수만 `total`에 누적한 뒤 `return`으로 결과를 돌려줍니다.

## 10. 기본값이 있는 함수 만들기

```python
def greeting(name, message="반갑습니다"):
    return f"{message}, {name}님!"


print(greeting("소희", "안녕하세요"))
print(greeting("소희"))
```

결과:

```text
안녕하세요, 소희님!
반갑습니다, 소희님!
```

**해설:** `message="반갑습니다"`처럼 작성하면 사용자가 두 번째 값을 주지 않았을 때 기본값이 사용됩니다.

## 11. 타입 어노테이션 작성하기

```python
def multiply(a: int, b: int) -> int:
    return a * b


print(multiply(4, 5))
```

결과:

```text
20
```

**해설:** `a: int`, `b: int`는 입력값의 타입을 표시하고 `-> int`는 반환값의 타입을 표시합니다.

## 12. 간단한 클래스 만들기

```python
class Student:
    def __init__(self, name, score):
        self.name = name
        self.score = score

    def is_pass(self):
        return self.score >= 60


student = Student("지수", 75)

print(student.name)
print(student.is_pass())
```

결과:

```text
지수
True
```

**해설:** `__init__`은 객체를 만들 때 실행됩니다. `self.name`, `self.score`는 각 객체가 가지고 있는 인스턴스 속성입니다.

## 13. 가장 많이 등장한 값 찾기

```python
from collections import Counter

fruits = ["apple", "banana", "apple", "orange", "banana", "apple"]

counter = Counter(fruits)

fruit, count = counter.most_common(1)[0]

print(fruit, count)
```

결과:

```text
apple 3
```

**해설:** `Counter`는 각 값의 등장 횟수를 셉니다. `most_common(1)`은 가장 많이 등장한 값 한 개를 반환합니다.

## 14. 날짜 계산하기

```python
from datetime import datetime, timedelta

today = datetime(2026, 8, 30)

after_week = today + timedelta(days=7)

print(after_week.date())
```

결과:

```text
2026-09-06
```

**해설:** `timedelta(days=7)`은 7일이라는 시간 차이를 나타냅니다. 날짜 객체에 더하면 7일 뒤 날짜를 구할 수 있습니다.

## 15. 이메일 형식 찾기

```python
import re

text = "문의는 hello@test.com 또는 python123@gmail.com 으로 보내주세요."

emails = re.findall(r"\w+@\w+\.\w+", text)

print(emails)
```

결과:

```text
['hello@test.com', 'python123@gmail.com']
```

**해설:** `\w+`는 문자·숫자 등이 한 번 이상 등장하는 부분을 찾습니다. `\.`은 실제 점(`.`) 문자를 의미합니다. `findall()`은 조건에 맞는 모든 문자열을 리스트로 반환합니다.
